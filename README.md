# 穿搭尺码推荐工具 🧥📏

根据身高、体重、体型，推算**上装 / 下装尺码**，也支持在浏览器内上传商品尺码表截图，匹配这件商品的尺码。

👉 **在线体验**：https://orangeedk.github.io/-chuan-da-chi-ma/

**浏览器识别测试版已接入**：截图识别及推荐均在用户浏览器运行，使用静态网站即可，不需要 Render 账号、绑卡或后端 OCR 服务。GitHub Pages 可直接提供上传截图和商品推荐功能，首次使用需要加载识别模型。

## 功能

- 上传商品尺码表截图，在页面上方显示商品推荐码数；支持上装与裤装
- 商品模式允许调整男款 / 女款及体型，版型效果选项不参与
- 商品推荐与通用身高体重模型分别标注，避免混淆
- 输入校验与实测胸围、腰围参与选码，修复增重反而降码的问题

- 输入身高 / 体重，自动推荐上装与下装尺码
- 体型选择：标准 / 偏瘦 / 健壮 / 肥胖，各自独立修正
- 支持腰围、裤长、衣长的定向微调（如「我腿长但腰细」）
- 内置与常见品牌公开尺码表规律的交叉校验，避免极端推荐
- 通用推荐保持不变；浏览器截图识别已在桌面 Chrome 测试，手机实机兼容性仍待验证

截图识别使用随网站提供的 ONNX Runtime Web 与 PP-OCRv4 模型。首次上传需要下载约 30 MB 的运行库和模型，后续可利用浏览器缓存；截图不上传到服务器。识别完成后沿用现有商品选码规则。已验证两张上装表和一张裤装表，准确读取全部尺码、围度及其他尺寸；这不代表所有截图或真实穿着效果均已验证。商品链接与登录入口继续搁置。

## 算法思路

- 以身高为主要基准、体重作修正项，按体型分档建立推算公式
- 针对健壮 / 肥胖体型有专项补偿（胸围、腰围、裤长分项调整），并带合理性检测：当选择体型与身材数据明显不匹配时给出提示而非硬套结果
- 具体推算逻辑与验证脚本见 `docs/`（开发中）

> ⚠️ 尺码推算基于常见公开尺码表规律的经验拟合，**不是**任何品牌官方尺码表，购买前请以商家页面为准。

## 本地运行

下载完整仓库，包括 `browser-ocr.js`、`product-size.js` 和 `vendor/onnx/` 模型目录。运行 `启动商品尺码预览.cmd` 后打开 http://127.0.0.1:8765/index.html，也可以使用任意普通静态网站服务。直接双击 HTML 时只能使用通用推荐，浏览器限制会阻止识别模型加载。

截图识别无需安装 Python OCR 依赖。Python 启动脚本仅用于本地网页预览；GitHub Pages 可直接托管这套文件。旧 Python OCR 和 Render 部署代码保留作为备用路径；当前浏览器方案不依赖这些识别服务。
## 开发

页面样式和字体嵌入 HTML，商品解析与本地识别服务独立保存：

```text
index.html                 页面与通用推荐
product-size.js            商品尺码表解析、上传及匹配
browser-ocr.js             浏览器识别与后台工作线程
vendor/onnx/               浏览器识别运行库、模型及字典
server.py                  本地静态页面与识别服务
ocr.ps1                    Windows OCR 备用实现
启动商品尺码预览.cmd         本地启动入口
product-link-worker.cjs     搁置的链接与登录测试代码
```

提交代码前可对照算法验证脚本做回归校验。
