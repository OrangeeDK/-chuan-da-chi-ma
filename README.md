# 穿搭尺码推荐工具 🧥📏

根据身高、体重、体型，推算**上装 / 下装尺码**，也支持在本地上传商品尺码表截图，匹配这件商品的尺码。

👉 **在线体验**：https://orangeedk.github.io/-chuan-da-chi-ma/

## 功能

- 上传商品尺码表截图，在页面上方显示商品推荐码数；支持上装与裤装
- 商品模式允许调整男款 / 女款及体型，版型效果选项不参与
- 商品推荐与通用身高体重模型分别标注，避免混淆
- 输入校验与实测胸围、腰围参与选码，修复增重反而降码的问题

- 输入身高 / 体重，自动推荐上装与下装尺码
- 体型选择：标准 / 偏瘦 / 健壮 / 肥胖，各自独立修正
- 支持腰围、裤长、衣长的定向微调（如「我腿长但腰细」）
- 内置与常见品牌公开尺码表规律的交叉校验，避免极端推荐
- 手机 / 电脑浏览器均可使用通用推荐；本地截图识别需要运行识别服务

**GitHub Pages 目前只支持通用推荐。** 当前截图识别使用本机 Python 服务和 OCR，GitHub Pages 不会运行这些服务。上传源代码不等于上线截图识别，在线识别服务尚未部署。商品链接与登录入口暂时取消，相关读取代码保留为测试代码。

## 算法思路

- 以身高为主要基准、体重作修正项，按体型分档建立推算公式
- 针对健壮 / 肥胖体型有专项补偿（胸围、腰围、裤长分项调整），并带合理性检测：当选择体型与身材数据明显不匹配时给出提示而非硬套结果
- 具体推算逻辑与验证脚本见 `docs/`（开发中）

> ⚠️ 尺码推算基于常见公开尺码表规律的经验拟合，**不是**任何品牌官方尺码表，购买前请以商家页面为准。

## 本地运行

下载完整仓库（至少包含 `index.html` 和 `product-size.js`），双击页面可使用通用推荐。

使用截图识别时，请在 Windows 安装 Python，运行 `启动商品尺码预览.cmd`，然后打开 http://127.0.0.1:8765/index.html 。默认优先使用本机 RapidOCR 模型，未安装时尝试 Windows OCR；需有对应中文 OCR 语言支持。可安装推荐的本地 OCR 依赖：

```sh
python -m pip install rapidocr-onnxruntime pillow numpy
```

身高体重及截图在本地处理，截图识别不调用云端服务。

## 开发

页面样式和字体嵌入 HTML，商品解析与本地识别服务独立保存：

```text
index.html                 页面与通用推荐
product-size.js            商品尺码表解析、上传及匹配
server.py                  本地静态页面与识别服务
ocr.ps1                    Windows OCR 备用实现
启动商品尺码预览.cmd         本地启动入口
product-link-worker.cjs     搁置的链接与登录测试代码
```

提交代码前可对照算法验证脚本做回归校验。
